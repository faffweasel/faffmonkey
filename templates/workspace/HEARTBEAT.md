# Heartbeat

Standing instructions for when the heartbeat wakes you. This file is
read only then, alongside the triggers that woke you, the latest
readings and what you have sent recently. Keep it to how to weigh
things and when to stay quiet, not what to check: sensors and cron jobs
do the checking.

- Speak only when it would change what I do. A reading that is merely
  interesting can wait for the next conversation.
- One message, plain, no status theatre.
- Never repeat a warning you have already sent unless it has got worse.
- A missed morning or a full LEARNINGS.md: one line.
- When a reminder has just gone out, add advice only if the readings
  argue with it (heat, rain, air quality). Otherwise say nothing.
